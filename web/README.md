# EduVice

EduVice (eduvice.org) helps immigrant parents understand the US school system. Parents ask a question in their own words, for example about enrolling a child, English-learner services, special education or school meals. A retrieval-augmented chatbot finds the most relevant passage in a curated school-system guide (stored in MongoDB Atlas Vector Search) and streams back a plain-language answer, with the source passage shown alongside it. The site is built with Next.js 14 (App Router), TypeScript, Tailwind CSS and next-intl. It starts in English and Spanish, and the layout uses logical CSS properties so right-to-left languages can be added later.

## Local setup

**Prerequisites:** Node.js 20.6+, a MongoDB Atlas cluster (the free M0 tier works), and a Gemini API key (free from [Google AI Studio](https://aistudio.google.com/apikey)).

```bash
cd web
npm install
cp .env.example .env.local      # then fill in MONGODB_URI and GEMINI_API_KEY
npm run seed                    # embeds data/seed-faqs.json, creates the vector index
npm run dev                     # http://localhost:3000 → redirects to /en
```

In Atlas, allow your IP under **Network Access** (on Vercel, allow `0.0.0.0/0`, because Vercel's IPs aren't fixed).

### Seeding the vector collection

`npm run seed` does the whole job:

1. Reads the FAQ chunks in `data/seed-faqs.json`.
2. Embeds each chunk with Gemini `gemini-embedding-001` (768 dimensions). Answers are generated by `gemini-3.8-flash`.
3. Upserts the chunks by `slug` into `MONGODB_DB.MONGODB_COLLECTION`, and removes chunks no longer in the file.
4. Creates the Atlas Vector Search index if it doesn't exist yet, then waits until the index is queryable.

To change the corpus, edit the JSON file and run the command again. If you'd rather create the index by hand (Atlas → **Search & Vector Search** → **Create Search Index** → **Vector Search** → JSON editor), name it `faq_vector_index` and use:

```json
{
  "fields": [
    { "type": "vector", "path": "embedding", "numDimensions": 768, "similarity": "cosine" }
  ]
}
```

### Project notes

- **Languages:** English, Spanish, Chinese (Simplified), Vietnamese and Arabic (right-to-left). UI text lives in `messages/<locale>.json` and guide topics in `data/faqs/<locale>.json`. English is the source of truth.
- **Translating:** after editing English text, run `npm run translate`. It uses Gemini to fill in only what's missing or changed: new UI keys, and topics whose English text changed (tracked by `sourceHash`). Hand-edited translations are kept. Options: `--only=messages|faqs`, `--locale=vi`, `--force`.
- **Adding a language:** add it to `locales` in `src/i18n/routing.ts` (and `RTL_LOCALES` if right-to-left), give it a name in `LANGUAGE` in `scripts/translate.ts` and in `LANGUAGE_NAMES` in `src/lib/prompt.ts`, add its native name under `LanguageSwitcher.names` in `messages/en.json`, run `npm run translate`, and register its FAQ file in `src/lib/faqs.ts`. If Poppins doesn't support its script, add a font in `[locale]/layout.tsx` and `globals.css`.
- **Search** uses only the English topics. Gemini's embeddings are multilingual, so questions in any language find the right topic.
- The colors are defined only in `src/app/globals.css` (`@theme`) and come from the brand palette. Tailwind's default colors are switched off.
- **Accounts (optional):** Auth.js (`src/auth.ts`) with Google, email sign-in links (Resend), and email + password (scrypt-hashed, and the email must be confirmed first: `/api/register`). Signed-in users' chats are saved in the `conversations` collection (`src/lib/conversations.ts`, `/api/conversations`). Their chat memory is loaded from the account, a guest chat is moved into the account on sign-in, and users can delete chats or their whole account (`/api/account`). Without `AUTH_RESEND_KEY`, emails are printed to the dev terminal (set `EMAIL_CONSOLE=1` to do this with `next start`). Google sign-in appears only when `AUTH_GOOGLE_ID`/`AUTH_GOOGLE_SECRET` are set.
- **Backgrounds:** the home page reuses the coming-soon page's scrolling college names (`UniversityNamesBackground.tsx`). Other pages use the doodle-path pattern.
- **Marg** is EduVice's chatbot ("marg" means "path"). The animated mascot is `src/components/Marg.tsx`, with animations in `globals.css` (`.marg…`): idle, wave, thinking and talking, and motion is off for people who prefer reduced motion.
- **Chat memory** is stored only in the visitor's browser (`localStorage`, key `eduvice.marg.chat.v1`, last 40 messages). The last 8 turns are sent with each question so Marg understands follow-ups. "New chat" clears it. Nothing is stored on the server.
- **Follow-up suggestions:** after each answer, the small router model suggests 3 next questions in the user's language (`src/lib/followups.ts`). They're sent after the answer, so they never delay it.
- **Google Search suggestions** are required by Google's grounding terms. They sit behind an EduVice-styled search button under web answers. To show them always, set `COLLAPSE_SEARCH_SUGGESTIONS = false` in `src/components/ChatBox.tsx`, and confirm Google's display requirements before launch.
- **How the bot answers** is set in `src/lib/prompt.ts`. EduVice answers any question: it uses and cites the school guide when a topic fits, and otherwise answers from Gemini's own knowledge, in the user's language. Edit the rules there. Keep the `[SOURCE]` / `[NO_SOURCE]` format line: the model starts each reply with one of these tags, and the API uses it to decide whether to show the source card, then removes it.
- **Web search:** Gemini has Google Search available for every question and uses it when it needs current or specific facts (dates, deadlines, local services, news). Simple questions don't trigger a search. The sites it used and Google's Search Suggestions are shown under the answer. Grounding with Google Search has a free daily quota on the Gemini API and is billed after that.
- **Response format:** `/api/chat` streams the answer as plain text. If the web was searched, a record-separator character (`\u001E`) and a JSON object with the sources follow at the end (see `src/lib/chat-protocol.ts`). The guide citation is sent in the `X-Source` header.
- **AP-credit search (stricter):** questions about which colleges give credit for AP exams (detected by a quick Gemini check in `src/lib/router.ts`) are answered with Google Search through Gemini instead of the guide (`src/lib/web-search.ts`). Only College Board (`collegeboard.org`) and official college sites (`.edu`) count: the model is told to search only those sites, and any sentence Gemini attributes only to other sites is removed. If no official source backs the answer, the bot says so. These answers aren't streamed, because sources are checked first.
- **Rate limit:** each visitor (identified by a hash of their IP) can ask 8 questions per minute and 100 per day. Counters are stored in the `rate_limits` collection and expire on their own. To change the limits, edit `LIMITS` in `src/lib/rate-limit.ts`.
- `/api/chat` streams `text/plain`. The cited source is returned in the `X-Source` response header as URI-encoded JSON.
